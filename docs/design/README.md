# Design files: Network Device Monitor

Screen designs for every screen, as editable SVG plus PNG previews. The colours, type sizes, spacing and radii are the exact values used in `frontend/styles.css`.

| File | Screen |
| --- | --- |
| `01-dashboard-desktop.svg` / `.png` | Dashboard (desktop) |
| `02-device-selected-desktop.svg` / `.png` | Device selected with history (desktop) |
| `03-dashboard-mobile.svg` / `.png` | Dashboard (mobile, 375 px) |

## Open them in Figma (2 minutes)
1. In Figma, create a **Design file** and open the **Screens** page.
2. Drag all the `.svg` files onto the canvas. Each becomes an editable frame with shapes and text.
3. Rename the frames, turn repeated parts into **Components** (cards, buttons, inputs), and add **Auto Layout** (follow `FIGMA_DESIGN_SPEC.md`).
4. Share the file with "Anyone with the link can view" and paste the link into the README.
Inter is the design font (the app uses the system font). Install Inter if the text looks different.
